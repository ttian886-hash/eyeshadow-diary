Eyeshadow Diary — personal PWA (v1)

IMPORTANT: Before moving to a new URL, export your FULL backup from the old app. Browser storage is tied to each site/origin. Import the backup into the hosted PWA. The ZIP does not include your current browser localStorage.

INSTALL (Android / Chrome):
1. Upload all files and folders in this ZIP to an HTTPS static web host (e.g. GitHub Pages), keeping paths unchanged. Do NOT open index.html directly from a ZIP or file:// path.
2. Open the HTTPS address in Chrome on your phone while online. Wait for the first load to finish.
3. Chrome menu > Add to Home screen / Install app.
4. Open the installed icon, import your full backup, then check counts and history.
5. After first online visit, the app shell and included image assets work offline.

LIMITATIONS:
- Personal data is stored locally in the browser (localStorage), NOT in the ZIP, on the server, or in the cloud. Clearing site data/uninstalling may remove it. Export backups regularly.
- Installing from a different origin does not automatically migrate data.
- New versions of index.html may require a service-worker cache version bump.
- This is a PWA, not a signed APK or Play Store listing.
