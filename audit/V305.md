# v305: preserve save/undo feedback on the current product

Review only. Production remains v304 until publication is authorized.

## Behavior

A successful save stays on the current detail page, retaining scroll position, and shows the existing +1 shade/product feedback. Saving from the picker settles into the collection at the same browsing position, with product-count feedback there too. The saved notification offers View look and Undo; only View look reveals the exact dated history entry and clears stale history filters. Undo restores the transaction and shows −1 feedback without navigating away. History edits retain their existing reveal behavior.

The notification remains available while any of its controls has keyboard focus. Reduced-motion users retain static signed feedback. No automatic delay or forced navigation is added.

## Validation

41 application/state checks, 7 collection checks, 14 isolated import checks and 14 mocked Firestore checks passed (76 total). Added cases verify staying in detail, optional exact-history navigation, missing-record rejection, picker destination and opposite save/undo feedback calls. Syntax and diff checks passed.

Six preview scenes at 320/390/768px verify count roundtrips, real signed feedback DOM, no automatic history navigation and notification bounds. Comparison fixtures intentionally hold real animation frames and feedback timers for inspection; production animations are not frozen. Real phone animation timing remains to be confirmed.
