# Eyeshadow Diary

A personal eyeshadow collection and makeup usage diary.

## Features

- Manage eyeshadow palettes and individual shades
- Track makeup looks and usage history
- View collection statistics
- Export and import data backups
- Progressive Web App (PWA) for desktop and mobile

## App

[Open Eyeshadow Diary](https://ttian886-hash.github.io/eyeshadow-diary/)

## Data & Backups

Data is stored locally in the browser unless explicitly transferred using the cloud features.

Always export a backup before updating or restoring data.
